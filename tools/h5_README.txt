大观园 · 游戏操作说明

【打开方式】
先完整解压正式版压缩包，再双击上一级目录中的“启动游戏.cmd”。
电脑需已安装 Node.js；服务启动后打开 http://127.0.0.1:8000/ 。
其他端口和部署方式见上一级《使用说明.txt》。直接双击 index.html 无法正常加载模块和模型。
等待全园加载完成，点击封面上的“入园”开始。完整资源已随包提供。

【俯瞰模式（默认）】
  鼠标左键拖动：旋转视角      滚轮：拉近拉远      右键拖动：平移
  左侧目录：点院落名飞到该处，并显示原著介绍
  F：从当前位置下到园中步行
  T：时间流动开 / 关      M：声音开 / 关      H：设置面板（画质、渲染比例、时辰、季节、语言）      P：隐藏 / 显示界面

【步行模式】
  W A S D（或方向键）：行走      按住鼠标拖动：转头 / 转视角      Shift：快走      空格：跳
  V：切换第一人称 / 第三人称      滚轮：第三人称时调远近
  E：靠近门窗时进屋 / 出屋；靠近任务目标时互动（拾取、对话、题匾）
  K：保存当前画面为图片      Esc：退出步行
  触屏设备：左下摇杆前行，右侧拖动转视角。

【剧情玩法】
  进入后可选择剧情：
  · 第十七回“大观园试才题对额”：跟着地上飘的花瓣引路，一处处走去，为院落题匾。
  · 第三十九、四十回：扮刘姥姥进大观园，跟着贾母一行游潇湘馆等处，与众人对话、选择应答。
  · 人物任务：扮演黛玉、宝玉、宝钗等，完成原著里的小故事：葬花、题帕、乞红梅、螃蟹宴、菊花诗……
  屏幕上方会提示当前目标，指南针显示方位和步数。

【画质与流畅度】
  设置面板里可选画质（低 / 中 / 高）和渲染比例。帧率持续偏低时，网页会自动降低渲染分辨率，流畅后再升回去。
