启动方法（Windows）
1. 将整个压缩包完整解压，不要直接在压缩包内运行。
2. 电脑需已安装 Node.js；本包无需 npm install，也无需构建。
3. 双击“启动游戏.cmd”，保持服务窗口开启。
4. 服务启动后，在浏览器打开 http://127.0.0.1:8000/ 。
5. 等待全园加载完成，在封面点击“入园”。
6. 结束时在服务窗口按 Ctrl+C，或关闭服务窗口。

若提示端口占用
不要直接使用已有服务，以免打开另一版本。
可在本文件所在目录打开 PowerShell，运行以下两行：
$env:PORT = '8005'
node .\serve.cjs
然后打开 http://127.0.0.1:8005/ 。

其他系统
在本文件所在目录运行 node serve.cjs，再打开程序输出的本地地址。
也可用支持 JavaScript 模块的静态 HTTP 服务部署 daguanyuan 目录。
请通过 HTTP 打开；直接双击 index.html 无法正常加载模块和模型。

包含内容
完整游戏源文件、全园模型与贴图、本地字体、预生成场景、预计算路线、
寻路后台线程，以及已验证的移动、转向遮挡修复。
游戏操作与素材说明位于 daguanyuan 目录内。
游戏资源已包含在包中；作品说明里的历史在线地址不保证与本包同版。

存档与校验
存档、画质和偏好保存在当前浏览器中，不随压缩包迁移。
更换浏览器或访问地址（包括端口）可能使用不同的本地存档。
manifest.json 记录发布版本及各文件的 SHA-256 校验值。
本包不含 Node.js 运行时、浏览器数据、测试页面、诊断日志或开发工具缓存。
