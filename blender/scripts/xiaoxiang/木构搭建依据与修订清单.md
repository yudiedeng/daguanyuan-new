# 潇湘馆木构：搭建依据与修订清单

2026-09-19。研究记录，本轮未修改 Blender 模型。

## 参考资料的边界

- 用户《图02-1潇湘馆室内空间格局》：用于内外柱列、三间室内空间、前廊及侧廊的相对关系。无标注尺寸，不能据此宣称实测柱距、柱高。
- 用户外观照片：用于可见屋顶、廊、墙和门窗形态。尚未证实其与空间格局图属于同一版本，不能不加核对就拼成一套复原方案。
- 清式构造资料：用于理解结构，不等于潇湘馆的专用设计图。不混用大式宫殿、清式小式与江南营造做法。

## 查证的基本关系

1. 抱头梁连接檐柱和金柱：一端在檐柱上，另一端插入金柱。不能把所有柱头间的斜杆当成抱头梁。
2. 檩沿面阔方向承接屋面；椽与檩交错，沿屋面坡向排列。梁与椽不能混作同一层构件。
3. 清式抬梁构架实例中，梁、瓜柱逐层承托上层梁和脊檩；屋顶不是四边柱顶直接连成的简单斜框。
4. 举架依据步架及檩的高程确定，不是任意抬高内圈柱子。檩面高差也不能不计节点直接视为柱身高差。

## 现有模型的问题

- 内外圈之间的“联系梁”统一斜接，缺少构件分类和节点依据。
- 部分侧廊连接杆止于尚不存在的内侧支承处；需逐一检查承托关系，不能悬空结束。
- 现状外柱身3.75m、内柱身4.75m是视觉试调，不是考证尺寸。柱身加高而柱径、梁截面不变，比例须连同屋架重新审视。
- 12×9m地台和室内尺寸是模型试定值；台边余量、廊宽、后侧铺面需纳入完整平面核对。
- 平面图缺少剖面，不能由两圈柱列直接断定完整屋顶类型和侧面屋架做法。

## 后续建模顺序与检查

1. 将参考平面整理为轴线图，区分图上可见信息与推定尺寸；保持正中入口和厅堂通道。
2. 先做一榀横向剖面，表示柱、水平梁、短柱、檩与屋面轮廓；确认檐口、脊高和出檐，再复制成整体。
3. 单独处理前廊、侧廊和转角，区分水平连接构件、屋面椽与角部构件，不统一套斜杆。
4. 检查每根梁的两端、每根檩的落点、椽的承托和交接；剖面、平面必须对应。
5. 构架确定后再加门窗隔扇、栏杆、望板和瓦；精细榫卯与做旧最后深化。
6. 每阶段保留总场景备份，提供俯视和剖面检查视角。所有构件仍可独立编辑。
