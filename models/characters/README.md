# 林黛玉网页人物

`lin-daiyu-web.glb` 使用完整第一版人物，保留原有抱书姿势和连续头颈。网页加载后按 1.74 米归一化，模型的 +X 正面转为角色容器的 +Z，脚底归零。

- 33 根骨骼，包含腰胯、双腿、分区裙摆与衣袖。
- 动作：Idle（3 秒）、Walk（1.2 秒）、FastWalk（约 0.87 秒）。全部为原地循环，不含水平根运动；位移仍由游戏碰撞控制器计算。
- 抱书的手臂、书和上身保持同一局部姿势。裙摆的摆幅较小，当前为动作初稿，尚需进一步检查台阶、急转弯与袖裙穿模。
- Meshopt 几何/动画压缩、2048 像素 WebP 贴图，约 1.26 MB。网页的 GLTFLoader 已启用 MeshoptDecoder。
- 保留原始网格面数；本次压缩未启用几何简化。

验证入口：通过 HTTP 打开 `/tests/character-visual.html`，检查人物切换、加载竞争、故障恢复、变换和动作恢复。
